# 多产品 · 多 SKU 资产档案目录规范

本目录用于存放不同产品线及各细分 SKU 的视觉防幻觉锚点、核心卖点参数与实拍底图，供反推工作流按需动态调用。

## 1. 目录结构约定

```text
products/
├── README.md                          # 本说明文档
├── _sku_template/                     # 新增产品/SKU 标准模板
│   └── product_brief_template.md
├── reymon-cat-litter/                 # 已就绪 SKU：瑞梦迪 5合1 植物膨润土混合猫砂（白茶款 2.5kg）
│   ├── product_brief.md
│   └── assets/
│       ├── packshots/                 # 外包装正视图、侧面图、多袋囤货实拍图
│       ├── inner_granules/            # 内料/膏体/材质纯微距实拍图、功能实测图（如结团图）
│       └── props/                     # 固定搭配道具或真实模特/宠物实拍图
└── <新产品或新SKU英文简称>/            # 对话中输入新 SKU 时自动按此结构创建
    ├── product_brief.md
    └── assets/{packshots,inner_granules,props}/
```

## 2. 日常如何切换或新增 SKU？

- **无需提前手动写复杂文档**：在每次开启新反推对话的「阶段 0：开局需求对齐」时，你可以直接对 AI 说：
  - *“这次还是用瑞梦迪 5合1 白茶款”*（直接读取已有档案）；
  - 或 *“这次换新品：瑞梦迪钠基矿砂 5kg 装，主打球形矿砂秒吸不粘底，包装图在这 `/path/xxx.png`”* —— AI 会在对话中直接根据你的输入建立 `products/<新SKU>/` 档案并挂载对应实拍图。
- **核心防幻觉提醒**：
  - **模式 A（全 AI 全片）**：强烈建议至少提供 **1 张正面高清无遮挡外包装图** + **1 张无花字遮挡的纯内料/材质微距真图**（详情页带大字标签的图仅作卖点阅读参考，不要直接连入生图节点以防文字串染）。
  - **模式 B（轻量 AI 钩子 + 实拍混剪）**：若前 3~6 秒钩子镜头里不出现产品包装（只演痛点冲突，产品留在后半段实拍里出镜），甚至**无需上传任何产品图**即可极速开跑钩子分镜！
